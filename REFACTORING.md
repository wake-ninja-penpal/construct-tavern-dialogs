# Ветви: рефакторинг на React / React Native

Ветка `react-refactor`. Цель — перевести редактор с одного файла
`public/vetvi/index.html` (13.5k строк vanilla JS/DOM) на компонентную
архитектуру React, пригодную для переноса на React Native.

## Принципы

1. **Ядро без DOM.** Вся логика данных живёт в `src/vetvi/core/` — чистый
   TypeScript без React и DOM. Сюда же в дальнейшем переедут normalize,
   экспорт/импорт, проигрыватель, layout групп. Это общий код для веба и
   React Native (RN использует те же типы, фабрики, геометрию и стор).
2. **Pass-through документ.** Документ хранится «как есть»: ядро типизирует
   и валидирует только известные поля, все прочие (переменные, персонажи,
   свои типы, журнал действий, поля будущих версий) доезжают в сохранение
   без потерь. Поэтому React-редактор и классическая версия работают с одним
   и тем же автосохранением.
3. **Совместимость данных.** Тот же ключ localStorage (`vetvi-autosave-v17`),
   та же обёртка `{project, vp, bend}`, serialize-версия 18, те же id/формулы
   геометрии (якоря `edgeAnchors`, пути `edgePathD`, `shadeHex`, сетка 26).
   Проект, отредактированный в React-версии, открывается в классической и наоборот.
4. **Классическая версия не ломается.** `public/vetvi/index.html` остаётся
   рабочим на протяжении всего порта; React-версия догоняет по функциям,
   затем классическая уходит в архив.

## Структура

```
src/vetvi/core/           — ядро (без DOM/React): типы, константы, фабрики,
                            геометрия, загрузка/сохранение, merge, пароли,
                            личность участника
src/vetvi/web/            — React DOM слой: стор, холст, карточки, связи,
                            инспектор, тулбар, SyncClient, окна синка
src/app/page.tsx          — точка входа React-версии (маршрут «/»)
src/app/vetvi-react.css   — стили (палитра классической версии)
public/vetvi/index.html   — классическая версия (не трогается)
mini-services/vetvi-sync/ — сервер совместного редактирования (SQLite)
```

## Что сделано (этап 1)

- Ядро: типы документа (ноды/связи/группы/реплики/исходы), константы и
  палитра оригинала, фабрики с дефолтами `addNode()`, геометрия якорей и
  путей связей (`shadeHex`, smooth-безье, Catmull-Rom), загрузка/сериализация
  с pass-through.
- Стор: классический ObservableStore + `useSyncExternalStore`; undo/redo
  (снимки, лимит 100); автосохранение в `vetvi-autosave-v17` (пауза 700 мс);
  выделение нод/связей; привязка к сетке 26.
- Холст: панорама мышью, зум колесом с фокусом на курсоре (0.25–3.0),
  сетка, «вписать всё», измерение карточек и пинов через layout-эффекты.
- Карточки нод: все 9 типов оригинала (Сцена, Квест, Диалог, Навык,
  Действие, Развилка, Переменная, Событие, Заметка), цветная полоса,
  статус, сворачивание (0/1/2), превью реплик и исходов, метки.
- Связи: SVG-пути smooth, стрелки, выбор связи, создание перетаскиванием от
  пина выхода (включая пины исходов развилки/действия), защита от дублей и
  самосвязей, связи из реплик/исходов рендерятся от измеренных портов.
- Инспектор: название, статус (идея/в работе/готово), палитра цветов + свой
  цвет, текст, описание диалога, редактор реплик (говорящий/текст/порядок),
  исходы развилки, удаление.
- Тулбар: имя проекта, добавление нод всех типов, undo/redo, счётчики,
  индикатор автосохранения, переход в классическую версию.

## Дорожная карта (дальние этапы)

2. **Данные и структура**
   - Группы/рамки/цепочки: отрисовка, вложенность, сворачивание, drag нод внутрь.
   - Реплики: вложенность (children, отступы 23px, глубина 10), пины реплик,
     связи из реплик, speaker-выпадалки из персонажей проекта.
   - Действия: редактор кнопок на карточке, условия.
   - Переменные: редактор, нода-переменная (режим/операция/значение), вход `tin=var`.
   - Условия исходов развилки.
3. **Редактирование как в оригинале**
   - Контекстные меню, двойной клик, рамка выделения, мультивыбор связей,
     дублирование (Ctrl+D), копирование/вставка нод.
   - Изгибы связей: точки (pts), орто-режимы 90/45, мосты, петли самосвязей,
     якоря подписей (lt/lp).
   - Заметки-стикеры на нодах (notes), HTML-форматирование текстов.
4. **Проигрыватель** (ядро: машина диалогов уже переносима без DOM)
   - Пошаговый проигрыватель, «проигрывать подряд», зацикливание,
     старт с ноды, «К ноде» с подсветкой реплики.
5. **Совместное редактирование**
   - Подключение vetvi-sync (socket.io), комнаты, пароли, merge-заявки,
     журнал действий с диффами и откатами, идентичность редактора.
6. **Хранилище**
   - IndexedDB (как в настройках оригинала), менеджер проектов, локальные
     копии, импорт/экспорт JSON (включая «Тексты (JSON) v3»).
7. **Горячие клавиши и настройки**
   - Реестр HK_DEFS с переназначением (совместимо с классической версией),
     патчноут с версиями, поиск по проекту и журналу.
8. **React Native**
   - RN-оболочка переиспользует `src/vetvi/core` полностью и `web/store`
     (он тоже без DOM). Потребуется: примитивы рендера карточек/связей
     (react-native-svg для путей), жесты pan/pinch (react-native-gesture-handler),
     хранилище (AsyncStorage/SQLite), сокет-клиент. Ядро менять не нужно.

## Как проверить совместимость

1. Открыть `/vetvi/index.html`, поработать, закрыть.
2. Открыть `/` (React-версия) — тот же проект на холсте.
3. Переименовать ноду, переместить, добавить связь.
4. Открыть `/vetvi/index.html` — изменения на месте.
